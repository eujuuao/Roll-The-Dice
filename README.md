## 💻 Sobre o projeto

O **Roll The Dice** é uma aplicação que simula o lançamento de dados, muito utilizada em jogos de RPG. 

### Funcionalidade:
- O usuário escolhe o tipo de dado (d4, d6, d8, d10, d12 ou d20).
- A aplicação envia uma requisição para o backend.
- O backend retorna um número aleatório simulando o resultado do lançamento.
